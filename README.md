# ReactJS Task 1 - Introduction

## 📌 Project Overview

This project is developed as part of **Assignment 2: ReactJS, AJAX, GitHub & Competitive Programming**.

The purpose of this project is to demonstrate the fundamental concepts of **ReactJS** by building a simple and interactive React application.

The application demonstrates **Components, JSX, Props, State, Event Handling, and Responsive Design**.

---

The main objectives of this project are to understand and demonstrate:

* What is ReactJS?
* Why ReactJS is used
* React Components
* JSX
* Props
* State
* Basic React project structure
* Event Handling
* Responsive web design

---

## 🚀 Features

### 1. ReactJS Components

The application is divided into reusable React components:

* **Header** - Displays the application heading and introduction.
* **StudentCard** - Displays student information using Props.
* **Counter** - Demonstrates State and Event Handling.

### 2. JSX

JSX is used to create the user interface using HTML-like syntax inside JavaScript.

### 3. Props

The `StudentCard` component receives student information from the parent component using Props.

The following information is passed:

* Name
* Course
* Graduation Year

### 4. State

The `Counter` component uses React's `useState` Hook to store and update the counter value.

It provides:

* Increase
* Decrease
* Reset

### 5. Event Handling

The application handles user interactions using React event handling.

The counter buttons use the `onClick` event.

### 6. Responsive Design

The application is designed to work properly on different screen sizes:

* Desktop
* Tablet
* Mobile

## 💻 How to Run the Project

Follow the steps below to run this project on your local computer.

### Step 1: Clone the Repository

Open a terminal or PowerShell and run:

```bash
git clone https://github.com/shashikryadav50-cyber/react-task-1.git
```

### Step 2: Navigate to the Project Folder

```bash
cd react-task-1
```

### Step 3: Install Dependencies

Install all required Node.js packages:

```bash
npm install
```

### Step 4: Start the Development Server

Run the following command:

```bash
npm run dev
```

### Step 5: Open the Application

After starting the development server, Vite will display a local URL in the terminal.

Usually, the application will be available at:

```text
http://localhost:5173/
```

Open this URL in your web browser.

### Step 6: Stop the Development Server

To stop the development server, press:

```text
Ctrl + C
```
